🐍 Snake Game – Feel Free To Play

A modern, interactive Snake Game built using HTML, CSS, and JavaScript.
Smooth animations, multiple speed levels, wall wrapping, and a clean green-themed UI make this game fun and addictive 🎮✨

🎯 Created by Bhavish Poojary

 
  
  
  
  🎮 Features

✅ Smooth snake movement
✅ Beautiful modern UI design 🌿
✅ Score tracking system 🧮
✅ Adjustable speed levels (1–9) ⚡
✅ Wall wrapping toggle (W key) 🧱
✅ Keyboard controls 🎯
✅ Instant restart option 🔄
✅ Lightweight & fast loading 🚀
✅ Fully responsive layout 📱💻        



🕹️ Controls
Key	Action
⬆️ ⬇️ ⬅️ ➡️	Move Snake
1 - 9	Change Speed
W	Toggle Wall Wrapping
Enter	Restart Game




🛠️ Technologies Used

🌐 HTML5

🎨 CSS3

⚡ JavaScript

🖥️ Canvas API




📂 How To Run Locally

Clone the repository:

git clone https://github.com/bhavishpoojary28/Feel-free-to-play-snake-game.git


Open the project folder:

cd Feel-free-to-play-snake-game


Open snake.html in your browser:

start snake.html


That’s it! 🎉 Enjoy playing 🐍
